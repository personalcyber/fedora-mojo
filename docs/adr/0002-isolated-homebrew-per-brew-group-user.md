# Give brew group users fully separate Homebrew installs, not a shared core

Homebrew access is gated to users in the FreeIPA-managed "brew group," and each such user gets a complete, independent Homebrew installation (own core, taps, and cellar) under their home directory, rather than one shared read-only core/taps with per-user cellars. We picked the simpler, fully-isolated model over the more disk-efficient shared-core model because it's easier to reason about and to reverse, and it avoids the permission complexity of a shared installation on a multi-user image — disk space is cheap enough that the duplication isn't a real cost.
